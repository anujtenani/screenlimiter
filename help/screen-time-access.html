When Screen Time access won't turn on

Last updated November 2026

iOS owns that switch, not Screen Limiter — so the app can only tell you where to look. There are three places it can be, and one of them is hidden by a bug.

What the permission actually is

Screen Limiter blocks apps through Apple's Screen Time framework. Before iOS will let it shield anything, the app needs authorization from Family Controls — the same permission Apple's own App Limits use. It is not a normal notification prompt that can be asked for again whenever it is convenient. iOS surfaces it once, and after that the only control is a switch in Settings.

Until that switch is on, Screen Limiter is a well-organised list of groups that cannot do anything. The onboarding screen says as much; it just doesn't look like a failure.

The switch, by its real name

Open Settings → Screen Time, scroll to the bottom, and look for Apps With Screen Time Access.

  • If Screen Limiter is listed there, turn it on and reopen the app.
  • If the section is there but Screen Limiter is missing, scroll the list — it follows install order.
  • If the section is missing entirely, skip to the next part of this page.

Not that Settings page. Settings → Screen Limiter only lists Siri & Search and a handful of system services. The permission is not there, and looking for it there is the most common reason people conclude the app is broken.

If "Apps With Screen Time Access" isn't there at all

This is an iOS bug, not a Screen Limiter setting, and it has one fix: reinstall.

  1. Delete Screen Limiter from the Home Screen.
  2. Reinstall it from the App Store.
  3. Open it, tap Continue, and allow Screen Time when iOS asks.

Be aware of what that costs: your groups, passcode and week of insights are stored on the device and go with the app. Reinstalling is the only reset Apple provides for this permission, which is precisely why it is the last step rather than the first.

If the switch is on and it still isn't working

  • Force-quit Screen Limiter and reopen it. The authorization state is read at launch and on returning to the app.
  • Answer the system prompt properly. If iOS showed "Allow" and the answer was no, the app cannot re-ask. Reinstalling is the only way to see it again.
  • Check Screen Time itself is on. If Screen Time is switched off at the top of Settings → Screen Time, every app that depends on it stops enforcing, including this one. Turning Screen Time back on can prompt to delete its usage history — declining that prompt cancels the change, so read it before tapping.
  • Restart the phone. Unglamorous, and it clears more wedged Screen Time state than any other step.

The three states, and what you see in the app

  • Not asked yet. The onboarding screen offers Continue, with the note that iOS will confirm next.
  • Denied. A banner reads "Screen Time is switched off", with a line about turning it back on in Settings → Screen Time. Nothing is blocked until it is.
  • Approved. Everything works, and the Settings row says so. No banner.

Diagnostics is the definitive answer

Settings → Diagnostics shows the raw authorization value and whether the shared app group is available, above the armed activities and the monitor's last wake-up. If authorization says approved and nothing is blocking, the problem is downstream of the permission and belongs on the limit isn't blocking page. If it says denied, it is this page.

Questions people ask about this

Why can't Screen Limiter just ask again?

Family Controls authorization is granted by the system, not the app. Apple designed it so an app cannot repeatedly prompt until you cave in. Once the answer is no, only Settings — or a fresh install — changes it.

Will reinstalling delete my groups?

Yes. Groups, the passcode and the week of insights live in the app's own container on this device, and there is no backup copy anywhere because nothing is uploaded. Recreate your groups after reinstalling.

Do iPad and iPhone keep separate permissions?

Each device grants its own Screen Time access. On iPad the switch is in the same place: Settings → Screen Time → Apps With Screen Time Access.

Does Screen Limiter see which apps I allow?

iOS gives the app an opaque token rather than an app name. The token can be resolved into a name on this device — that is how a new group suggests its name — and it means nothing off it. Nothing is uploaded, so there is no server-side record of your access, your groups or your apps. The privacy policy is one page.
