Passcode, Parent Mode and getting back in

Last updated November 2026

The passcode is a lock on the settings, not on the phone. Knowing exactly which is which is the difference between a limit that holds and a lockout that ruins a weekend.

What the passcode protects

It is not a lock on the phone. It is a lock on Screen Limiter's settings, and it covers the things that would otherwise make every limit optional in one tap:

  • Editing a group's allowance, window, strictness or app selection.
  • Deleting a group.
  • Pausing all limits.
  • Removing the passcode or resetting everything.

Without one, the only person a limit protects you from is the version of you who would not open the settings. That is a real person, which is why deleting the app is the honest escape hatch rather than something the app pretends it can prevent.

How it is stored

The code is kept as a salted hash in the keychain, never as the code itself. That has two consequences worth stating plainly:

  • Nobody — not the app, not us — can read it back.
  • If there is no security question, there is no recovery.

The security question

When you set a passcode you can also set a question and answer. Forgot passcode? on the passcode screen asks the question and, on a correct answer, clears the old code so you can set a new one. The answer is matched case-insensitively after trimming spaces; it is not a password, it is a way back to your own settings.

Set it. The alternative is deleting the app and rebuilding every group, and that is a genuinely irritating afternoon.

Parent Mode

Parent Mode hands the code to someone else: Screen Limiter locks itself, every change needs their code, and the security question is the route back once they have it. Two uses:

  • On a child's phone. You keep the code; they can use the allowances but cannot edit them.
  • On your own phone. Someone else holds the code, which is a stronger promise than one you made to yourself at midnight.

Parent Mode is not a substitute for Apple's Screen Time parental controls. It protects this app's settings; it does not stop the phone being reset or the app being deleted.

Locked out with no security question

There is one way out, and it is the same one Apple's frameworks leave for every app in this category: delete Screen Limiter and reinstall it. That removes the passcode and every group, passcode and insight with it. It is the lock doing its job — an unlockable lock would be a formality.

Changing or removing the code

  • Change it — Settings → Passcode → Change passcode, current code first.
  • Remove it — Settings → Passcode → Remove passcode. In Parent Mode this needs the parent's code.
  • Start over — Settings → Reset everything. Every group, insight and the passcode are deleted, and limits stop immediately.

This is not your Screen Time passcode. Apple's passcode (Settings → Screen Time → Lock Screen Time Settings) protects App Limits and Downtime, and iOS alone manages it. Screen Limiter's passcode is separate, and this page is about that one.

Questions

Can support reset my passcode?

No. The code exists only as a hash on your device, and there is no account or server that could hold a copy. That is the point of it.

Does the passcode block deleting the app?

No, and no third-party app can do that on an iPhone. iOS gives apps no hook into their own removal. A passcode protects the settings; it is not a device management tool.

What happens to Parent Mode if I restore from a backup?

The lock state is part of the app's saved state and comes back with the backup, including the parent's code — which is why the security question is the only recovery that does not involve starting over.
